# Desafío - Inmobiliaria ADL 🏠

Este es mi proyecto para el Desafío 4 del curso de desarrollo Fullstack. Consiste en una página web para una inmobiliaria que carga tarjetas de propiedades dinámicamente utilizando JavaScript.

## 📋 Funcionalidades

- **Página Principal (`index.html`):** Muestra un resumen con las primeras 3 propiedades en venta y 3 en alquiler.
- **Páginas Secundarias:** Muestran el catálogo completo de propiedades filtradas por categoría (Venta o Alquiler).
- **Renderizado Dinámico:** Las tarjetas se generan desde un arreglo de objetos en JS utilizando `.map()`, _template literals_ y manipulación del DOM.
- **Lógica Condicional:** Los íconos y textos de "mascotas" y "fumar" cambian automáticamente (color y símbolo) dependiendo de si están permitidos o no en cada propiedad.

## 🛠️ Tecnologías Utilizadas

- HTML5 & CSS3
- Bootstrap 5 (Grillas y estilos responsivos)
- JavaScript (Módulos y Vanilla JS)
- FontAwesome (Íconos)

## 🚀 Cómo ejecutar el proyecto

Debido a que el proyecto utiliza módulos de JavaScript (`type="module"`), no funcionará si solo abres el HTML con doble clic.

Para visualizarlo:

1. Abre la carpeta del proyecto en tu editor de código (como VS Code).
2. Haz clic derecho en `index.html` y ábrelo utilizando la extensión **Live Server**.
